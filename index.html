📲 Sinkronkan HP ↔ Laptop

📱 Anda sedang membuka ini di HP?

Seluruh perubahan yang baru Anda simpan di HP (termasuk Tim SMP ALFAYYADH, pemain, official, skor) tersimpan aman di HP ini. Gunakan tombol di bawah untuk mentransfernya ke Laptop:

💡 Langkah: Klik "Salin Kode Data", kirim ke chat WA sendiri / panitia, lalu buka WA Web di laptop dan tempel di tab "Terima di Laptop".

Unduh file backup lengkap data turnamen, kirim via email/drive/WA dokumen, lalu upload di laptop.

💻 Anda sedang membuka ini di Laptop?

Tempel kode yang tadi Anda salin dari HP ke kotak di bawah ini, lalu klik "Sinkronkan Sekarang". Data laptop akan langsung terupdate 100%!

☁️ Sinkronisasi Otomatis Antar-Semua Perangkat (Supabase)

Ingin setiap kali panitia mengedit di HP langsung OTOMATIS tampil di laptop dan HP penonton tanpa perlu salin kode manual?

⚠️ Jika Muncul Pesan "Unauthorized / RLS Violation":

Supabase database memerlukan izin akses tulis publik (nonaktifkan RLS). Salin script 5-baris ini dan jalankan di menu SQL Editor di dashboard Supabase Anda: 

ALTER TABLE public.teams DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.matches DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.tournament_config DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.moments DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.sponsors DISABLE ROW LEVEL SECURITY;
